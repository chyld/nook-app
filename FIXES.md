# Review of alpha's changes

One row per finding of `CHANGES-REVIEW-FINDINGS.md` (the change numbers are those of
`CHANGES-REVIEW.md`). The code as alpha left it was copied aside before any fix. "Fails before"
means the test was run on that copy (its own bundle, server and sources) and failed. Where a
test needs a name the old code did not export, the old logic was given that name in the copy
only. "Broken on purpose" means the test checks behaviour that already worked, so it was seen to
fail with the code broken by hand, and then the code was restored. New test files:
core `changes.test.ts`, server `changes.test.ts`, web `changes.test.ts`, e2e `changes.test.ts`.

The rule for U+00A0 (findings 4, 5, 14, 24) is in `core/src/style/blank.ts` and SPEC-NOTES.md
("The kept space"). It is content: no code counts it as blank or drops it. To the person it is
a space: it separates words, search and plain-text copy treat it as a space, and table cells
already did.
